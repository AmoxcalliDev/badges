## 🛡️ Amoxcalli Badges — v0.0.1

First public release of the dynamic SVG badge engine powering **badges.amoxcalli.dev**.

### ✨ What's included

**Available endpoints:**

- `GET /api/v1/github/badge/followers/{username}` — Badge displaying the follower count of a GitHub user.
- `GET /api/v1/github/badge/contributor/{organization}/{username}` — Badge that checks whether a user has contributed (merged PR) to a GitHub organization. Displays `Contributor` or `Future Contributor`.

**Infrastructure:**

- Flat SVG rendering on the server side.
- 100% offline icons via Iconify (SimpleIcons, Lucide, Tabler) — no external image dependencies.
- `Cache-Control` headers optimized for Cloudflare and GitHub Camo (`s-maxage=3600`, `stale-while-revalidate=86400`).
- Compact number formatting (e.g. `12.3k`, `1.2M`).

### 🚀 Stack

Next.js 16 · TypeScript · Octokit · @iconify/json · Cloudflare
