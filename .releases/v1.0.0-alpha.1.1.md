## 🛡️ Amoxcalli Badges — v1.0.0-alpha.1.1

### 🆕 What's new

**Twitch — Status badge**

New endpoint that displays whether a streamer is currently live.

```
GET /api/v1/twitch/badge/status/{username}
```

```markdown
![Twitch Status](https://badges.amoxcalli.dev/api/v1/twitch/badge/status/YOUR_USERNAME)
```

Shows `ONLINE` or `OFFLINE` with Twitch purple branding.

---

### ⚙️ Internal improvements

- **Generic SVG badge utility** (`getBadgeSvg`) — reusable badge builder with configurable icon, label casing, and right panel color. GitHub badges refactored to use it.
- **Better-Auth integration** — authentication layer added (foundation for the upcoming SaaS dashboard).
- **Prisma + PostgreSQL** — database setup with migration history for user sessions and accounts.
- **Docker** — updated to `node:22-alpine`, database service added to both `docker-compose.yml` and `docker-compose-dev.yml`.
- **Icon loading** — improved mechanism in `iconHelper` via updated `next.config.ts`.

---

### 🔧 New environment variables

```env
# Twitch
TWITCH_CLIENT_ID=your_twitch_client_id
TWITCH_CLIENT_SECRET=your_twitch_client_secret

# Database
DATABASE_URL=your_database_url

# Better-Auth
BETTER_AUTH_SECRET=your_secret
BETTER_AUTH_URL=https://your_domain
```
