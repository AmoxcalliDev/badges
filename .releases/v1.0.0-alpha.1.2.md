## 🛡️ Amoxcalli Badges — v1.0.0-alpha.1.2

### 🆕 What's new

GitHub — Contributors badge

New endpoint that displays the total number of distinct users with merged pull requests in a GitHub organization, excluding bot accounts.

```http
GET /api/v1/github/badge/contributors/{organization}
```

```markdown
![GitHub Contributors](https://badges.amoxcalli.dev/api/v1/github/badge/contributors/YOUR_ORG)
```

Shows a compact contributors count with GitHub branding.

GitHub — Repository last release badge

New endpoint that displays the latest published release tag for a repository.

```http
GET /api/v1/github/badge/repository/last-release/{owner}/{repository}
```

```markdown
![GitHub Release](https://badges.amoxcalli.dev/api/v1/github/badge/repository/last-release/YOUR_ORG/YOUR_REPO)
```

Shows the latest release tag, or `no releases` when the repository has no published releases.

GitHub — Repository license badge

New endpoint that displays the detected repository license.

```http
GET /api/v1/github/badge/repository/license/{owner}/{repository}
```

```markdown
![GitHub License](https://badges.amoxcalli.dev/api/v1/github/badge/repository/license/YOUR_ORG/YOUR_REPO)
```

Shows the SPDX identifier when available, with fallbacks for repositories that expose a different license payload.

### ⚙️ Internal improvements

• GitHub badge routes were refactored to use shared utility functions for contributors, followers, releases, licenses, and API error handling.
• GitHub API failures now map to clearer badge responses such as `rate limited`, `org not found`, `invalid org`, `bad token`, `network error`, and `unavailable`.
• Badge responses now share a reusable SVG content type helper plus unified cache headers across GitHub and Twitch routes.
• Cache strategy was improved with `Cache-Control`, `CDN-Cache-Control`, and `Vercel-CDN-Cache-Control` headers for better edge and CDN behavior.
• The existing `contributor` and `followers` GitHub badges were updated to use the same hardened response and caching layer.
• Production analytics support was added through Umami in the app layout.

### 🔧 Tooling and infra

• Project dependencies were refreshed, including Next.js `16.2.9`, React `19.2.7`, Prisma `7.8.0`, Better Auth `1.6.20`, and Biome `2.5.1`.
• PostCSS configuration was moved to TypeScript and updated to use the Tailwind CSS PostCSS plugin.
• Docker Compose setup was adjusted to fix the PostgreSQL image/version and volume configuration.
• Linting and formatting setup was cleaned up around Biome, including schema and rule updates.

### ✅ Notes

• No new environment variables are required for this release.
• Existing GitHub, Twitch, database, and Better Auth setup from `v1.0.0-alpha.1.1` remains valid.

Authentication and platform coverage keep moving forward. This alpha expands the GitHub badge catalog while making badge delivery more consistent at the cache and API-response layers.
